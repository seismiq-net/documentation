SeismiQ Sensor Documentation
================

Documentation site built with [VitePress](https://vitepress.dev). Requires Node.js 20.19+
(a `.nvmrc` pins the version used in CI — run `nvm use` to match it).

```shell
npm install
npm run docs:dev      # dev server with hot reload
npm run docs:build    # build into docs/.vitepress/dist
npm run docs:preview  # preview the production build
```

Or with [just](https://github.com/casey/just): `just dev`, `just build`, `just preview`.
